# Phase 6: UI Polish for Recruiter Demos

> Date: 2026-04-30

## 1. Empty State / Onboarding

- Replace current empty chat with a focused, minimal input area
- Small chat box centered on screen with placeholder: "Drop your job description link, paste text, or upload a PDF"
- File upload icon (for PDF/doc upload support)
- Simple send button only (no extra controls)
- Clean, inviting feel - recruiter should immediately know what to do

## 2. Sidebar Polish

- Clean up chat history list styling
- Better visual hierarchy for role names vs timestamps
- Group by role or status if possible
- Overall tighter, more polished look

## 3. Right Sidebar / JD Context Card

- Claude-style right sidebar or floating card panel
- After JD is ingested, show a persistent card with:
  - Job title + company
  - Key requirements (extracted/summarized)
  - Location, comp range, team info if available
  - Quick-reference for the recruiter throughout the pipeline
- Card should be collapsible/dismissible but visible by default
- Updates as the pipeline progresses (candidate count, stage, etc.)

## 4. Tool Cards

- Current tool cards are acceptable, no changes needed now

## 5. Visual Identity (Later)

- Branding, colors, typography
- Making it feel like a polished product, not a raw chatbot
- Defer to after demo feedback

## Priority Order

1. Empty state (highest impact for first impression)
2. Right sidebar JD card (most useful during demos)
3. Sidebar polish
4. Visual identity (post-demo)
